# Snowflake SnowPro Core (COF-C03) Study Guide

Revision notes for the Snowflake SnowPro Core certification exam, COF-C03 version. Put together from the official COF-C03 exam study guide outline and the Snowflake documentation.

**[Download the PDF](snowpro-core-cof-c03-revision-guide.pdf)** (58 pages, A4) or **[read it here on GitHub](snowpro-core-cof-c03-revision-guide.md)**.

## What's covered

The notes follow the official exam domains in order:

| Domain | Weight |
|---|---|
| 1. Snowflake AI Data Cloud Features and Architecture | 31% |
| 2. Account Management and Data Governance | 20% |
| 3. Data Loading, Unloading, and Connectivity | 18% |
| 4. Performance Optimization, Querying, and Transformation | 21% |
| 5. Data Collaboration | 10% |

Also included:

- cheat sheets: numbers worth memorising, which feature fits which scenario, and pairs that are easy to mix up
- the five official sample questions with explanations
- 40 practice questions with answers
- a checklist for the last couple of days before the exam

## COF-C03 vs COF-C02

COF-C03 replaced COF-C02 in 2026. Most of the old material still applies, but the new exam spends more time on:

- Gen2 and Snowpark-optimized warehouses
- Apache Iceberg tables and dynamic tables
- Snowpipe Streaming
- Snowflake Cortex (AI SQL functions, Cortex Search, Cortex Analyst) and Snowflake ML
- Snowflake CLI, Notebooks, Streamlit and Git integration
- Trust Center, privacy policies, alerts and data lineage
- Data clean rooms and Native Apps

These get extra attention in the notes. Where a limit has changed recently (VARIANT size, multi-cluster limits, Snowpipe pricing), both the old and new values are mentioned, since older practice tests still use the old ones.

## Exam format

100 questions, 115 minutes, passing score 750 out of 1000, US $175. Check the [official certification page](https://learn.snowflake.com/en/certifications/snowpro-core-c03/) before booking, as these details can change.

## Corrections

Snowflake ships changes often, so some details will go stale. If you spot something wrong or outdated, open an issue or a pull request.
